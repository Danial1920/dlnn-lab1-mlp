# Диагностика обучения MLP

Лабораторная работа № 1 по DLNN: бинарная классификация `make_moons`, сравнение активаций, инициализации, заданных режимов оптимизации и глубины сети. Основная реализация и объяснения находятся в [notebook.ipynb](notebook.ipynb), отчёт — в [report.pdf](report.pdf).

По среднему validation loss эпохи 100 выбрана конфигурация **F**, внутри неё **seed 29**. Test loss — **0.131385**, test accuracy — **0.950000**. Test использован только после выбора по validation.

## Установка и запуск

Эксперимент выполнен с **Python 3.12.14**, **PyTorch 2.15.0**, на **cpu**, `torch.set_num_threads(1)`. CUDA и MPS не используются. Зависимости зафиксированы в `requirements.txt`; подробности — в `results/environment.json`. На другой платформе или с другими версиями возможны небольшие численные различия.

Из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/run_notebook.py
```

В Windows активация: `.venv\Scripts\activate`.

Скрипт запускает все ячейки в новом Jupyter-ядре из активного окружения и сохраняет выполненный `notebook.ipynb`. Он заново выполняет 12 экспериментов, перезаписывает файлы `results/` и семь графиков `figures/`, формирует сравнительные таблицы, выбирает модель и оценивает test. Модели обучаются с нуля; предварительно сохранённые веса и доступ в интернет после установки пакетов не требуются. `report.pdf` этой командой не пересобирается.

Альтернатива: открыть `notebook.ipynb` в Jupyter или VS Code, выбрать Python из `.venv`, выполнить **Restart Kernel and Run All**. Для Jupyter-интерфейса потребуется отдельная установка JupyterLab; он не нужен для запуска скриптом. Рабочая папка при интерактивном запуске — корень репозитория.

Ноутбук содержит статический численный анализ выполненного эксперимента. Если меняются версии, данные или настройки, анализ и отчёт необходимо сверить с новыми результатами.

Для пересборки PDF из существующих результатов и графиков:

```bash
python -m pip install reportlab==4.4.9
python scripts/build_report.py
```

Скрипт использует шрифт DejaVu Sans из установленного Matplotlib. При необходимости путь к TTF можно задать переменной `REPORT_FONT`. Пересборка PDF не запускает обучение. Часть интерпретаций в отчёте относится к сохранённому эксперименту; после изменения протокола их нужно обновить.

## Экспериментальный протокол

Данные: `make_moons(n_samples=2400, noise=0.25, random_state=2026)`. Стратифицированные разбиения с `random_state=2026`: сначала `test_size=0.2`, затем `test_size=0.25`. Train/validation/test: **1440/480/480**, по классам **720/720**, **240/240**, **240/240**. `StandardScaler` обучается только на train. Входы `float32`, метки `torch.long`.

MLP: 2 входа, скрытые слои ширины 32, линейный выход из 2 логитов. Cross-entropy с `reduction='mean'`; accuracy — доля от 0 до 1. Для скрытых слоёв Xavier normal использует `gain=1.0`, He normal — `mode='fan_in', nonlinearity='relu'`. Выход всегда Xavier normal с gain=1; все смещения нулевые.

| Код | Слоёв | Активация | Инициализация скрытых | Оптимизатор | LR | Параметров |
|---|---:|---|---|---|---:|---:|
| A | 6 | Sigmoid | Xavier normal | Adam | 0.003 | 5442 |
| B | 6 | Tanh | Xavier normal | Adam | 0.003 | 5442 |
| C | 6 | ReLU | Xavier normal | Adam | 0.003 | 5442 |
| D | 6 | ReLU | He normal | Adam | 0.003 | 5442 |
| E | 6 | ReLU | He normal | SGD | 0.05 | 5442 |
| F | 1 | ReLU | He normal | Adam | 0.003 | 162 |

Каждая конфигурация: seed **11 и 29**, **100 эпох**, batch size **128**, перемешивание каждую эпоху. Перед созданием модели — `torch.manual_seed(seed)`, отдельный DataLoader generator — `10000 + seed`. Для SGD momentum=0, остальные параметры оптимизаторов по умолчанию. Нет scheduler, dropout, batch normalization, weight decay, early stopping и предобучения.

Полные train/validation метрики записываются в `eval/no_grad` до обучения и после каждой эпохи. Для A/C/D измеряются нормы Фробениуса градиентов скрытых весов на первых 128 объектах train на эпохах 0, 20, 100. Диагностический backward не обновляет веса; градиенты очищаются до и после, режим модели восстанавливается.

Выбор: минимум среднего val_loss эпохи 100 по двум seed, при точном равенстве — более ранняя буква; внутри конфигурации — меньший val_loss, при равенстве seed 11. Оцениваются веса эпохи 100, а не лучшей промежуточной эпохи. Итоговые состояния хранятся в памяти текущего запуска; повторный запуск воспроизводит обучение.

Поля `metrics.csv`: `config, seed, epoch, train_loss, train_accuracy, val_loss, val_accuracy`. Поля `gradients.csv`: `config, seed, epoch, layer, gradient_norm`.

## Интерпретация

Sigmoid начинает медленнее, что согласуется с малыми ранними градиентами. He меняет масштаб градиентов, но не гарантирует меньший итоговый validation loss. Глубокая D лучше подгоняет train, а F получает меньший средний validation loss. У SGD в заданном режиме видны скачки train/validation loss; особенно заметен переход с эпохи 99 на 100.

Выводы ограничены двумя seed, одним разбиением и заданными LR. A–C сравниваются при конкретном Xavier gain=1; D–E одновременно меняют оптимизатор и LR; D–F — глубину и число параметров. Эти эксперименты не доказывают универсального превосходства одной активации, оптимизатора или глубины.
